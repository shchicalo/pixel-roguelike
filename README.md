# Pixel Roguelike

Браузерная 2D pixel-art roguelike с видом сверху.

## Управление

- **ПК:** WASD — движение, мышь — прицеливание, ЛКМ — выстрел, R — перезарядка, Q/Й — Импульс.
- **Телефон:** в главном меню выберите «ТЕЛЕФОН». Левый виртуальный джойстик отвечает за движение; правый — за направление и непрерывную стрельбу. Кнопки вверху экрана отвечают за паузу, перезарядку и Импульс (если он открыт).

## Запуск локально

Откройте `index.html` в современном браузере.

## Публикация на GitHub Pages

Загрузите `index.html`, `game.js` и `README.md` в корень репозитория. GitHub Pages: Settings → Pages → Deploy from a branch → `main` → `/(root)`.

После публикации сайт будет доступен по адресу `https://shchicalo.github.io/pixel-roguelike/`.
