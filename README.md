# Pixel Roguelike — обновление 4.5

Обновление содержит:
- Экран выбора персонажа с карточками Стрелка и Охотника.
- Покупку Охотника за 100 монет.
- Сохранение покупки и выбранного персонажа в localStorage этого браузера.
- Оружие и характеристики персонажей, включая дальность стрельбы.
- Дробовик Охотника: 5 пуль веером, 5 урона за пулю, 6 патронов на обойму.
- Выстрел касанием по игровому полю в мобильном режиме.

## Обновление GitHub Pages
1. В репозитории открой `game.js`.
2. Нажми Edit (карандаш).
3. Замени содержимое целиком содержимым нового `game.js`.
4. Нажми Commit changes.
5. Обнови сайт с очисткой кэша: Ctrl+F5.

`index.html` менять не нужно: он по-прежнему загружает `./game.js`.

Покупка Охотника и выбранный герой сохраняются в localStorage текущего браузера/устройства. Между устройствами они пока не синхронизируются.
