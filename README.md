# Pixel Roguelike — обновление 4.7

## Модельки персонажей

- Все семь персонажей используют отдельные 16×16 пиксельные спрайты, которые рисуются непосредственно в `game.js`.
- Спрайт Стрелка обновлён по присланному образцу: тёмный капюшон, фиолетовые детали, видимая часть лица и ружьё, направленное вправо.
- Спрайт поворачивается вместе с персонажем к курсору или правому мобильному джойстику.
- Спрайты остальных героев остаются отдельными: Охотник, Алхимик, Медик, Инженер, Разведчик и Электрик.

## Финальная минута после Гоблина

- После победы над Гоблином его анимация завершения проходит как раньше.
- Затем начинается дополнительная 60-секундная финальная минута.
- Игрок возвращается в обычную канализацию 200×200; обычные волны врагов снова появляются.
- В HUD отображается обратный отсчёт финальной минуты.
- Если игрок выживает до конца таймера, появляется экран победы.
- Если игрок погибает раньше, показывается экран окончания забега.

## Публикация на GitHub Pages

Замените в репозитории файл `game.js` этим файлом и нажмите **Commit changes**. `index.html` менять не нужно. После завершения GitHub Pages обновите сайт через Ctrl+F5.
