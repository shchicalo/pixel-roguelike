# Pixel Roguelike

Браузерная версия 2D pixel-art roguelike.

## Запуск локально

Откройте `index.html` в современном браузере.

## Публикация на GitHub Pages

1. Загрузите `index.html`, `game.js` и `README.md` в корень репозитория.
2. Откройте Settings → Pages.
3. В разделе Build and deployment выберите `Deploy from a branch`.
4. Выберите ветку `main` и папку `/(root)`, затем нажмите Save.
5. После публикации сайт будет доступен по адресу `https://shchicalo.github.io/pixel-roguelike/`.

Игра запускается автоматически после загрузки страницы; главное меню появляется первым.
